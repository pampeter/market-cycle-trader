# 📱 Deriv AI Bot: phone app (PWA)

This is the phone-app version of [`deriv-ai-rise-fall-bot`](../deriv-ai-rise-fall-bot/). Install it from your browser. It **runs entirely on your phone**, with no server: the app connects straight to Deriv's WebSocket API and, optionally, to Groq.

**App link (once merged to `main`):** <https://pampeter.github.io/market-cycle-trader/deriv-bot/>

## Install on Android

1. Open the link above in **Chrome**.
2. Tap **Install** on the blue banner, or use the **⋮ menu → Install app** (it may say *Add to Home screen*).
3. Open **Deriv Bot** from your home screen. It opens full screen like a normal app.

On iPhone, open the link in Safari and tap **Share → Add to Home Screen**.

## Connect your Deriv account

1. On Deriv, **switch to your Demo account**.
2. Go to **Account Settings → API token** (<https://app.deriv.com/account/api-token>) and create a token with the **Read** and **Trade** scopes.
3. In the app, open **Settings**, paste the token and tap **Test connection**. You should see your login ID, whether it's a Demo or Real account, and your balance.
4. Optional: paste a free **Groq API key** (<https://console.groq.com/keys>) to turn on the LLM second opinion.

Your keys are stored **only on your phone** (in the browser's local storage). They are sent only to Deriv and Groq. To remove them, use **Settings → Forget my keys**.

## Using it

- **Paper mode** (the default) simulates trades on live Deriv prices, using real payout quotes. No orders are sent.
- **Live mode** places real contracts on the account your token belongs to. You have to type **YES** to confirm. The app refuses to trade a **real-money** account unless you tick *Allow a real-money account*.
- The bot stops by itself when today's P/L reaches the **profit target**, or when it hits the daily loss limit, the max trades, or the losing-streak limit. Today's counters (by UTC date) are saved, so closing and reopening the app doesn't reset them.
- **Keep the app open with the screen on.** Phones pause web apps that are in the background. The app keeps the screen awake while it runs (you can turn this off in Settings) and reconnects when you come back to it. A contract that is already open always settles on Deriv, even if the app is closed.

## Same engine as the Python bot

| | |
|---|---|
| ML | Logistic regression retrained on every tick using the last 100 ticks (return, momentum, volatility, EMA8−EMA21, SMA5−SMA10). Its results match scikit-learn to within about 0.0003 |
| LLM | Groq (`openai/gpt-oss-120b` by default). Replies with JSON `{direction, confidence, reason}`. A trade needs ML ≥ 60 %, LLM confidence ≥ 78, and both agreeing on direction |
| Risk | Profit-target auto-stop, daily loss limit (it also skips a trade that could push you past the limit), max trades per day, losing-streak stop, cooldown, **no martingale** |

## Development

```bash
# serve locally (any static server works)
python3 -m http.server 8080      # then open http://localhost:8080/deriv-bot/

# tests (Node 22+, Python with `websockets` for the fake Deriv server)
cd deriv-bot
PYTHON=python3 node --test tests/engine.test.mjs
npm i --no-save jsdom && PYTHON=python3 node tests/ui.smoke.mjs
```

## ⚠️ Risk warning

Volatility Indices are generated by a random number generator. No model can reliably predict them. A win pays about +95 % of your stake and a loss costs 100 %, so a coin-flip win rate loses money over time. The profit target only controls **when the bot stops**; it doesn't make reaching the target more likely. Only trade money you can afford to lose. Start with paper mode, then use your demo account.
